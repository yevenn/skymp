# Plugins of our own

Shipped in the client package (`package-client.ps1` puts every plugin here in the
game copy's `Data`), and part of the server's load order like any other.

| Plugin | Why |
|---|---|
| `Unofficial Skyrim Special Edition Patch.esp` | An empty stand-in (no records, master-flagged like the real one). Ultimate Markarth lists USSEP as a master, but USSEP for game 1.6.1170 (4.3.8a) lists the free Creation Club files as masters, which the Numidium game copy leaves out. Ultimate Markarth uses three USSEP records: two placed objects, which don't appear, and an NPC package (NPCs are off). Never install the real USSEP next to it: it has the same name |
